# Skills do projeto

Skills próprias do Bora Estudar 2.0. Cada uma é uma pasta com um `SKILL.md`:

```
.claude/skills/
└── nome-da-skill/
    └── SKILL.md
```

O `SKILL.md` começa com frontmatter — `name` e `description` — e a
`description` decide quando a skill é carregada. Escreva-a dizendo **quando
usar**, não o que a skill é.

Boas candidatas neste projeto: procedimentos repetidos que a constituição
exige e que não cabem num comando (rodar a bateria de checagens antes de um
merge, gerar tipos depois de uma migration, publicar uma release).

Regra: skill descreve **procedimento**; a constituição descreve **regra**;
os comandos descrevem **etapa do fluxo SDD**. Não misture os três.
